# EURO AI weekly re-scan

A scheduled GitHub Actions job (Mondays 09:00 IST) re-checks the open EURO AI vendor catalogue and the EU AI Act deadline list published at https://unadhi.com/platform/ and writes a digest to `digests/` (`LATEST.md`, plus a ready-to-send e-mail text).

- **No subscriber data lives here.** People opt in by e-mail; the list stays in the EURO AI mailbox, and the digest is sent from there (BCC). Reply UNSUBSCRIBE to stop.
- Standard library Python only. `actions/checkout` is MIT-licensed.
- Suggestions only, not legal advice. Primary sources: EUR-Lex Reg. (EU) 2024/1689 and 2026/1744.
